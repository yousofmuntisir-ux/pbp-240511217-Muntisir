### 3. Eksplorasi Platform

**A. Web Platform**

Web Platform digunakan untuk membuat aplikasi yang dapat diakses melalui browser.

Teknologi yang digunakan:
- HTML
- JavaScript

Hasil praktikum:

**B. Desktop Platform**

Desktop Platform digunakan untuk mengembangkan aplikasi yang berjalan pada komputer.

Teknologi yang digunakan:
- Java
- JDK

Hasil praktikum:
`Hello, Desktop Platform!`

Mobile Platform digunakan untuk mengembangkan aplikasi yang berjalan pada perangkat mobile seperti smartphone dan tablet.

Salah satu lingkungan pengembangan yang dapat digunakan adalah Android Studio.

| Platform | Kelebihan | Kekurangan |

| Mobile | Praktis digunakan melalui smartphone | Perlu menyesuaikan perangkat |
